# 📱 Как открыть приложение на телефоне

## Способ 1: Через OneDrive (самый простой!) ⭐

### На Android:

1. **Установи приложение OneDrive** (если ещё не установлено)
   - Скачай из Google Play Store

2. **Открой OneDrive** на телефоне
   - Войди под своим аккаунтом

3. **Найди папку:**
   ```
   OneDrive → Projects → Plug-ins → Vibe-coding → Sport
   ```

4. **Нажми на файл `index.html`**
   - Выбери "Открыть в браузере" или "Chrome"

5. **Готово!** Приложение откроется в браузере

### На iPhone:

1. **Установи OneDrive** из App Store

2. **Открой папку:**
   ```
   OneDrive → Projects → Plug-ins → Vibe-coding → Sport
   ```

3. **Нажми на `index.html`**
   - Выбери "Открыть в Safari"

4. **Готово!**

---

## Способ 2: Создать ярлык на главном экране (удобнее!) 📲

### Для Android Chrome:

1. Открой `index.html` через OneDrive (как выше)

2. В браузере нажми **три точки** (меню) → **"Добавить на главный экран"**

3. Назови: "Тренировки" или "Мой Зал"

4. Теперь приложение как обычное приложение на главном экране!

### Для iPhone Safari:

1. Открой `index.html` в Safari

2. Нажми кнопку **"Поделиться"** (квадрат со стрелкой)

3. Выбери **"На экран "Домой"**

4. Готово! Ярлык на главном экране

---

## Способ 3: Через хостинг (если хочешь постоянную ссылку)

Если хочешь чтобы приложение было всегда доступно по ссылке (не зависело от OneDrive), можно загрузить на бесплатный хостинг:

### Вариант A: GitHub Pages (бесплатно)

1. Создай аккаунт на GitHub.com
2. Создай новый репозиторий (назови "gym-tracker")
3. Загрузи все файлы из папки Sport
4. В настройках репозитория включи GitHub Pages
5. Получишь ссылку типа: `https://твой-ник.github.io/gym-tracker/`

### Вариант B: Netlify (бесплатно, ещё проще)

1. Зайди на netlify.com
2. Перетащи папку Sport в окно браузера
3. Получишь ссылку типа: `https://случайное-имя.netlify.app/`

## 💡 Рекомендация:

**Для рабочего компа:** Используй Способ 1 или 2 (OneDrive)
- Не нужно ничего устанавливать/настраивать
- Все файлы уже в облаке
- Работает везде где есть OneDrive

**Если хочешь делиться с друзьями:** Используй Способ 3 (хостинг)
- Постоянная ссылка
- Открывается у всех
- Не зависит от OneDrive

## ⚠️ Важно:

### Если приложение не работает с OneDrive:

**Проблема:** Некоторые функции могут не работать из-за ограничений OneDrive

**Решение:** Используй хостинг (Способ 3) или:

1. Сохрани папку Sport **локально на телефоне**:
   - OneDrive → Папка Sport
   - Три точки → "Сохранить на устройстве" → "Сохранить"
   - Скачай все файлы

2. Открой через файловый менеджер:
   - Найди папку Sport на телефоне
   - Открой index.html в браузере

## 📝 Частые вопросы:

**Q: Сохраняется ли прогресс на телефоне?**
A: Да! Все данные (веса, история) сохраняются в браузере телефона.

**Q: Нужен ли интернет?**
A: Нет, после первого открытия работает полностью офлайн.

**Q: Можно ли открыть на компе и на телефоне одновременно?**
A: Да, но история будет храниться отдельно на каждом устройстве.

**Q: Как синхронизировать данные между телефоном и компом?**
A: Пока синхронизация не реализована. Каждое устройство хранит свою историю.
