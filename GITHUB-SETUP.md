# 🚀 Установка приложения на GitHub Pages

## **Шаг 1: Создай иконки**

1. Открой файл `generate-icons.html` в браузере (Chrome)
2. Нажми "Скачать icon-192.png"
3. Нажми "Скачать icon-512.png"
4. Положи оба файла в папку `Sport` (где все остальные файлы)

---

## **Шаг 2: Создай GitHub аккаунт** (если ещё нет)

1. Перейди на https://github.com
2. Нажми "Sign up"
3. Создай аккаунт (бесплатный)
4. Подтверди email

---

## **Шаг 3: Создай новый репозиторий**

1. Залогинься на GitHub
2. Нажми зеленую кнопку **"New"** (или "+") → "New repository"
3. Заполни:
   - **Repository name**: `workout-tracker` (или любое название на английском)
   - **Description**: "Gym workout tracking app"
   - ☑️ **Public** (обязательно!)
   - ☑️ Поставь галочку "Add a README file"
4. Нажми **"Create repository"**

---

## **Шаг 4: Загрузи файлы**

### Вариант A: Через веб-интерфейс (проще)

1. На странице своего репозитория нажми **"Add file"** → **"Upload files"**
2. Перетащи ВСЕ файлы из папки `Sport`:
   ```
   ✅ index.html
   ✅ styles.css
   ✅ script.js
   ✅ manifest.json
   ✅ service-worker.js
   ✅ icon-192.png
   ✅ icon-512.png
   ✅ CHANGELOG.md
   ```
3. Внизу напиши: "Initial commit"
4. Нажми **"Commit changes"**

### Вариант B: Через GitHub Desktop (удобнее для обновлений)

1. Скачай GitHub Desktop: https://desktop.github.com
2. Установи и залогинься
3. File → Clone repository → выбери свой репозиторий
4. Скопируй все файлы из `Sport` в папку репозитория
5. В GitHub Desktop увидишь изменения
6. Напиши "Initial commit" и нажми "Commit to main"
7. Нажми "Push origin"

---

## **Шаг 5: Включи GitHub Pages**

1. В своем репозитории перейди в **Settings** (вкладка сверху)
2. Слева найди **"Pages"**
3. В разделе **"Source"** выбери:
   - **Branch**: `main`
   - **Folder**: `/ (root)`
4. Нажми **"Save"**
5. Подожди 1-2 минуты
6. Появится ссылка типа:
   ```
   https://твой-username.github.io/workout-tracker/
   ```

---

## **Шаг 6: Открой на телефоне**

1. Открой ссылку на телефоне в Chrome:
   ```
   https://твой-username.github.io/workout-tracker/
   ```
2. Проверь что всё работает

---

## **Шаг 7: Установи как приложение (PWA)**

### На Android:

1. Открой в Chrome браузере
2. Нажми **меню** (3 точки справа вверху)
3. Нажми **"Установить приложение"** (или "Add to Home screen")
4. Готово! Иконка 💪 появится на главном экране

### На iPhone:

1. Открой в Safari
2. Нажми кнопку **"Поделиться"** (квадрат со стрелкой)
3. Прокрути вниз → **"На экран «Домой»"**
4. Готово!

## **Как обновлять приложение:**

### Способ 1: Через веб-интерфейс
1. Открой свой репозиторий на GitHub
2. Найди нужный файл (например, `script.js`)
3. Нажми на него → значок карандаша (Edit)
4. Внеси изменения
5. Внизу "Commit changes"
6. Через 1-2 минуты обновления появятся на сайте

### Способ 2: Через GitHub Desktop (удобнее)
1. Измени файлы в локальной папке репозитория
2. GitHub Desktop покажет изменения
3. Commit → Push
4. Готово!

## **Проблемы?**

### Сайт не открывается
- Подожди 2-3 минуты после включения GitHub Pages
- Проверь что выбрал ветку `main` и папку `/ (root)`
- Проверь что репозиторий **Public**, а не Private

### Кнопка "Установить" не появляется
- Проверь что открыл в Chrome (не в приложении Instagram/Facebook)
- Проверь что сайт работает по HTTPS (GitHub Pages автоматически даёт HTTPS)

### Изменения не появляются
- Обнови страницу (Ctrl+R или перезапусти приложение)
- Очистить кэш: Settings → Storage → Clear site data
